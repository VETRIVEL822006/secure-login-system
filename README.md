# Secure Login System

## Description

A secure web-based login system built using Flask and SQLite.

## Features

* User Registration
* Secure Login
* Password Hashing
* Session Management
* Logout Functionality
* SQLite Database

## Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS

## Security Features

* Password hashing using Werkzeug
* Session-based authentication
* User validation

## How to Run

1. Install Flask:
   pip install flask

2. Run:
   python app.py

3. Open:
   http://127.0.0.1:5000
